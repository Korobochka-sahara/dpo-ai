# Данные проекта

В папке `data/` находятся данные, используемые для обучения и тестирования моделей анализа тональности.

Структура:

- `raw/` — исходные данные, загруженные с Kaggle;
- `processed/` — очищенные и подготовленные данные;
- `README.md` — описание структуры данных.

Используемый датасет:
- Amazon Reviews Dataset  
  https://www.kaggle.com/datasets/bittlingmayer/amazonreviews

Датасет не хранится в репозитории из-за большого размера.
