# Тесты проекта

В проекте реализованы базовые тесты с использованием `pytest`.

## test_api.py

Проверяет:
- корректный запуск FastAPI приложения;
- доступность endpoint `/`;
- доступность `/health`;
- корректность работы `/predict`;
- корректность структуры JSON ответа API.

---

## test_model.py

Проверяет:
- загрузку production-модели;
- корректность inference pipeline;
- наличие:
  - prediction;
  - confidence score;
- принадлежность prediction к допустимым классам;
- корректность диапазона confidence (`0 <= confidence <= 1`).

---

## Назначение тестов

Тесты используются для проверки:
- корректной загрузки модели;
- стабильной работы inference;
- работоспособности API;
- отсутствия критических ошибок после изменений в проекте.

---
