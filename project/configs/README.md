# Конфигурационные файлы

В данной папке находятся конфигурации проекта.

## Файлы

### `config.py`

Централизованный конфиг проекта.

Содержит:
- пути к данным;
- пути к моделям;
- пути к артефактам;
- основные директории проекта.

Используется во всех модулях:
- preprocessing;
- training;
- inference;
- API;
- tests.

---

## Зачем нужен config.py

Позволяет:
- избежать хардкода путей;
- упростить перенос проекта;
- централизованно управлять структурой проекта.
