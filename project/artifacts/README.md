# Артефакты проекта

В данной папке хранятся артефакты, полученные в ходе обучения, анализа и тестирования моделей.

## Структура

### `models/`

Содержит production-артефакты финальной модели:

- либо: 
  - `model.pkl` — обученная ML-модель (для sklearn/CatBoost);
  - `vectorizer.pkl` — TF-IDF vectorizer;
  - `label_encoder.pkl` — encoder классов;
- либо:
  - сохранённая DistilBERT модель;
  - tokenizer HuggingFace.

Используются FastAPI сервисом для inference.

---

### `mlflow/`

Логи экспериментов MLflow:

- метрики;
- параметры моделей;
- сравнение экспериментов;
- сохранённые run'ы.

Используется для выбора лучшей модели.

---

### `*.png`

Графики и визуализации из EDA:

- распределение классов;
- длина текстов;
- результаты анализа данных.

---

## Важно

Большие модели и крупные датасеты не загружаются в GitHub.

В репозитории находятся:
- только необходимые артефакты;
- sample data;
- конфигурации и код для воспроизводимости проекта.
